# 🏆 30-Day Codeforces Logic Building Bootcamp (Python)

> Structured day-by-day guide from **beginner → Codeforces Specialist** level.
> Language: **Python 3** (PyPy3 recommended on Codeforces for speed)

---

## 📅 Curriculum Overview

| Phase | Days | Topics |
|-------|------|--------|
| 🟢 **Foundation** | 01–05 | Fast I/O, Data Types, Loops, Lists & Strings, Built-ins |
| 🔵 **Core Structures** | 06–10 | dict/set/Counter, Stack/Queue/Heap, Sorting & bisect, Two Pointers, Prefix Sums |
| 🟡 **Intermediate** | 11–15 | Recursion & Backtracking, Greedy, Number Theory, Bit Manipulation, DP Intro |
| 🟠 **DP Deep Dive** | 16–20 | Knapsack, LCS/LIS, Grid DP, Graph BFS/DFS, Shortest Path |
| 🔴 **Advanced** | 21–25 | Trees, Segment Trees, DSU, String Algorithms, Combinatorics |
| 🟣 **Competitive Edge** | 26–30 | Advanced Graphs, Binary Search on Answer, Game Theory, Templates, Mock Contest |

---

## 🐍 Python vs PyPy3 on Codeforces

| | CPython 3 | PyPy3 |
|-|-----------|-------|
| Speed | Slower (use for easy problems) | 3–5x faster |
| TLE risk | Higher | Much lower |
| Recommendation | **Always submit PyPy3 first** | ✅ |
